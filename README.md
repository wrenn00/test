# 운동 기록 — 홈 와이어프레임

사진으로 남기는 운동 기록 앱. 홈 화면의 상태별 와이어프레임을 코드로 옮긴 것.

## 홈의 규칙

화면은 하나고 카드만 바뀐다.

| 상태 | 카드 | 사용자가 할 일 |
|---|---|---|
| 기록 0 | 아직 기록이 없어요 | 첫 기록 남기기 |
| 계획 없음 | 계획된 운동이 없어요 | 계획 세우기 또는 바로 기록 |
| 미션 | 앱이 제안한 운동 + 근거 | 수락 / 거절 |
| 계획됨 | 운동 목록, 0/3 | 완료 기록 |
| 완료 | 운동 목록, 1/3 | 기록 보기 |

- 아래 버튼은 언제나 `운동 기록하기`. 미션만 예외로 수락/거절.
- 계획은 카드 안 작은 행에서 추가한다.
- 상단 숫자는 달력의 사진 있는 칸을 센 값이다.
- 접기는 상태가 아니라 모든 상태에 적용되는 토글. 미션은 접히지 않는다.

## 실행

```bash
npm install
npm run dev
```

상단 스위처로 다섯 상태와 접힘, 미션 팝업을 확인할 수 있다.
